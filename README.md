# The Self-Producing Artist System - Landing Page

A high-converting VSL (Video Sales Letter) landing page for **The Self-Producing Artist System** by New Era Artist™.

## 🎨 Design Overview

This landing page features a clean, modern design with a strategic color palette:

- **Primary Background**: White (#FFFFFF) - Creates a clean, professional foundation
- **Primary Text**: Black (#000000) - Maximum readability and contrast
- **Accent Color**: Cotton Candy Blue (#A8D8EA) - Used strategically for CTAs, highlights, and visual interest

The color ratio follows the reference design: predominantly white with black text and Cotton Candy Blue accents used sparingly for maximum impact.
